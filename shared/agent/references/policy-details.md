# Навигация по правилам фреймворка

Это индекс совместимости, не полный протокол. Не загружать все документы по ссылкам.
AGENTS / role-orchestration.md определяет событие и обязательный модуль; SKILL.md — тактику активной роли.

| Событие | Модуль |
| --- | --- |
| Начало/пересмотр планирования | [planning.md](planning.md) |
| Рабочие MD, прогресс и случайные находки | [task-state.md](task-state.md) |
| Исполнение, Fast-Track, Low Energy, /strict; атомарный шаг и четыре фазы | [execution.md](execution.md) |
| Проверки, reverse explain, Diff Review, /deferred | [validation.md](validation.md) |
| Смена роли, Handoff, восстановление после compaction | [handoff.md](handoff.md) |
| Выявленный пробел, учебный журнал, карточки | [learning-journal.md](learning-journal.md) |
| Недельные метрики по запросу | [metrics.md](metrics.md) |
| Создание MD-плана / шаблон договорённостей | [plan-template.md](plan-template.md) |

Пути отсчитываются от каталога этого индекса, не от рабочего проекта или папки skill.
Если среда указала абсолютный путь policy-details.md, брать соседние модули из того же каталога.
В OMP доступны установленные references/*.md; при чтении исходника AGENTS через symlink использовать его исходный каталог.
Если нужный модуль недоступен, сообщить точный путь и остановить зависящее от него действие; не восстанавливать правила по памяти и не читать весь гайд вместо них.
