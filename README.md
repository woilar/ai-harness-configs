# AI Harness Configs

Личные глобальные конфигурации AI harness для работы и обучения на Java.
Каждый инструмент находится в своей папке и имеет собственную установку.

| Harness | Состояние | Настройка |
| --- | --- | --- |
| Oh My Pi | Готовая конфигурация: Copilot, Coach, Executor | [omp/README.md](omp/README.md) |
| DeepSeek Harness | Место для будущей конфигурации | [deepseek-harness/README.md](deepseek-harness/README.md) |

## Начать после распаковки

Из папки `ai-harness-configs` на Mac/Linux:

```bash
bash omp/scripts/install.sh --dry-run
bash omp/scripts/install.sh
```

Установщик подключает пять объектов из `omp/agent/` к стандартному глобальному
каталогу `~/.omp/agent/`. Существующие другие настройки сохраняются.
При конфликте он останавливается до изменений; порядок объединения описан
в [инструкции OMP](omp/README.md).

Полный [гайд](docs/engineering-ai-skills-guide.md) объясняет режимы и содержит
все установочные тексты. Шаблон договорённостей уже включён в общую политику.

## Режимы

- **Copilot:** основной напарник — исследует факты, задаёт вопросы, помогает
  сформулировать собственный план. Рабочий код не пишет.
- **Coach:** учит недостающей основе через объяснения и практику. Явный Coach
  сохраняет обучение даже для маленькой задачи.
- **Executor:** выполняет понятный согласованный микрошаг, проверяет его и
  запрашивает самостоятельное объяснение diff.

## Хранить в GitHub и обновлять

Создайте свой репозиторий и загрузите содержимое этой папки, включая `.gitignore`.
Служебная папка `.git` в архив не включена; новую историю создаёт владелец.
После клонирования установка выполняется той же командой выше.

При обновлении клонированного репозитория:

```bash
git pull
```

Символические ссылки продолжают указывать на обновлённые файлы. Затем запустите
новую сессию OMP. Если переместили репозиторий, нужно исправить прежние ссылки;
установщик покажет их как конфликт.

## Изменять настройки и добавлять другой harness

Актуальные тексты OMP находятся в `omp/agent/`. При изменении синхронизируйте
соответствующие блоки гайда; загрузка справочников остаётся ленивой.
Новый harness получает соседнюю папку со своим README, конфигурацией и установщиком.

Договорённости задач, учебный журнал, данные входа и история сессий остаются
в рабочих проектах или по личному пути. Общие правила находятся в этом репозитории.

## Проверить установщик

Для тестов нужен Python 3; для самой установки достаточно Bash и стандартных
утилит Mac/Linux:

```bash
python3 omp/tests/test_install.py
```

Тесты используют временные целевые папки и не меняют глобальную конфигурацию.
